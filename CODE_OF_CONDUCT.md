# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1, as its Code of Conduct.

In short: be respectful, assume good faith, and help keep this a welcoming and
harassment-free community for everyone, regardless of background or identity.
Maintainers may remove, edit, or reject contributions, comments, and other
interactions that don't align with the Covenant, and may temporarily or permanently
ban any contributor for behavior they consider inappropriate.

## Reporting

If you experience or witness behavior that violates this Code of Conduct, please report
it privately to the maintainer. Reports will be reviewed and handled confidentially.
