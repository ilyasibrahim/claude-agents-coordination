# Support

- **Questions / how-to:** start a
  [Discussion](https://github.com/ilyasibrahim/claude-agents-coordination/discussions),
  or read the README and the `INDEX.md` guides in `claude-user/` and `claude-project/`.
- **Bugs:** open an issue using the **Bug report** form.
- **Proposals** (new agents/commands/skills, protocol changes): open an issue using the
  **Proposal** form *before* sending a PR.
- **Security:** see [SECURITY.md](SECURITY.md) — report privately, not in a public issue.

This is a community project maintained on a best-effort basis. Please be patient and
respectful.
